# OctavaPlot backlog

Status register of the project: what is open, what is built and how far it was checked, what is known to be missing, and the defects that were fixed. It is the companion of [ROADMAP.md](ROADMAP.md), which holds the decisions, the architecture rules and the performance table. Item IDs (`OP-`, `DOC-`, `P8-`) come from two outside reviews, `OctavaPlot_Improvement_Plan.md` and a plotting addendum, checked against the source of 27 October 2026.

## To do

1. **Beta-testing.** Release the app to a small group and collect defects and requests. Start from [Not yet tried in a browser](#not-yet-tried-in-a-browser), which lists the controls that were tested in code only. Browsers verified so far: Edge 142 and Chrome (the Playwright tests); Firefox and Safari are not verified.
2. **Statistics taken from R.** Add calculations that exist in R, with reference values from R in the tests (the testing rule of the roadmap: independent values, never a second call into the same implementation). The contract for each calculation goes in [calculation-contracts.md](calculation-contracts.md) first. Items dropped on 1 November 2026 that this reopens: ROC, residual plots, Q-Q and Bland–Altman plots, the exact binomial interval, Holm and Benjamini–Hochberg corrections, and validation of the curve fits other than the two-phase exponential against outside references. This widens the scope the roadmap gives under "Out of scope" (ANOVA, mixed models, model selection), so the roadmap is to be updated with the first item that is taken up.

3. **Tooling.** Add `knip` as a devDependency with an `npm` script (it is named in the checks above but is not installed), choose a few lint rules (hook dependencies, floating promises) after counting their hits, and try the stricter compiler flags (`noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noImplicitOverride`, `noImplicitReturns`, `verbatimModuleSyntax`) by counting the errors each gives first.

## How to read the status

| Label | Meaning |
|---|---|
| **Tested** | Unit tests (and SVG export tests where stated) pass. Nothing was looked at by hand. |
| **Browser** | Also tried in Chrome (by a script or a person), or covered by a Playwright spec in `e2e/` (`npm run e2e`). |
| **Measured** | Timed on the production build with `npm run perf`. |

A line that does not say **Browser** was not tried in a browser. "Not done" inside an item records a limit of what was built; it is not planned work.

Checks run before a change is accepted: `npx vitest run`, `npx tsc --noEmit` and the browser tests (`npm run e2e`); `npx knip` is wanted for dead code but is not a dependency yet (see Tooling in the to-do list), so the dead code of 14 November 2026 was found with scripts. State on 14 November 2026: 206 test files, 4 792 tests passed, 57 browser tests passed (6 more are measurements); type check clean. The recorded drawings of 100 setups (`src/chart/export/__snapshots__/family-baseline.json`) change only when a drawing is changed on purpose.

## Status by area

### Data tables and project files

- **Sparse tables in the file** (1 Nov 2026). Only cells with a value, a subject or an exclusion are written, as `[row, value]`; cell and row IDs are written only when they are not the canonical ones of their place. The version stays 1; files of the earlier table shape are refused (owner's decision). Tested (`tableFile/tableCodec.test.ts`, `serialize.test.ts`). Not measured: the open time of a project of 100 000 observations after this change. Not done: tables with random IDs (earlier builds, or after a row was inserted) still write the ID of every cell that has a value.
- **Migrations** (`src/state/migrate.ts`). A version chain (empty; the runner is tested with injected steps) and a shape chain (`one-layer`, `group-gaps-folded`, `pair-lines-one-colour`). Tested against three real files written at commits f301af0, 8bf2d86 and df99336 (`src/state/fixtures`). Not done: a version bump (it would make older builds refuse new files; the owner decides). The old `equal` scaling and old heat-map palette IDs are handled where the setting is read, not as steps.
- **Change a table's type or subtype** (4 Nov 2026). `changeTableKind` changes the type in place, one undo step; rows, columns and values stay; the layout of subcolumns is dropped or rebuilt (`restructureGroups`) for the chosen options; graphs whose type no longer fits take the first type of the new kind; calculations that no longer apply are removed (the dialog says which). Browser (`e2e/tableType.spec.ts`). Not done: columns are not matched by meaning (a mean column and its SD), and data that does not suit the new type is not checked.
- **Factors** (28–29 Oct 2026). A `factor` on the first column of a grouped series (Factor…), in the file and in CSV (a "<Group> factor" column, recognised by name right after the data column). Tested; the dialog was looked at in Chrome. Limits: a real column named "<previous column> factor" is read as the factor column; a tab-separated paste carries no factor; CSV import of sized tables is untested. The `subject` of each observation that came with it was removed on 14 Nov 2026 (see Dropped).
- **Rows, CSV, fill.** Insert, delete and duplicate rows; CSV import preview with delimiter and decimal choice, BOM, `NaN` and `Infinity` text, duplicate or empty headers, refusal above 100 000 data lines; CSV export of all rows, included rows or with exclusion columns; Ctrl+D and Ctrl+R fill; Rows → Fill series… (start, step; one undo step). Browser.
- **Decimal separator** (OP-001). One setting decides how numbers are shown, edited, copied and exported; there is no thousands separator; CSV is semicolon-separated in comma mode. Round-trip tests for edit, paste, copy and CSV.
- **Autosave and recovery.** Autosave to `localStorage` is flushed on page exit; two tabs do not overwrite each other's recovery copy (revision check); an unreadable autosave is backed up at start-up; a project restored from recovery counts as not saved to a file. Ctrl or Cmd+S saves the file. The status line clears on the next action.
- **Date, time and duration columns** (P8-010, 29 Oct 2026). For the X column of an XY table (`Group.time`: date, datetime, duration); ISO 8601 only; a zone-less time is a wall-clock reading stored as UTC; an offset is converted with a visible count; times shown in UTC; calendar ticks. Rules: contracts section 17. Tested under four machine time zones. Not done: Y columns, survival times, histogram values, category axes; a major interval in calendar units; minor ticks on dates; local zones; fits and equal units on a time axis (warned). Not tried in a browser: the "X type…" dialog, the CSV type suggestion, the limit, break and extra-tick fields.

### Chart families

- **Survival.** Kaplan–Meier and cumulative events, with a Greenwood band, at-risk table, event marks and error bars. A **survival summary** analysis (subjects, events, censored, median survival or "Not reached", entries left out; no interval for the median, since the contracts name no method) reads the table through the same function as the chart. Browser for the summary.
- **Bars at numeric X** (`xyBars`, 28 Oct 2026). A bar from `bars.baseline` to Y at each X; the room of an X is the smallest distance between X values; several series stand side by side. Tested; Browser (gallery preview). Not done: bar widths from a column, labels above the bars, bars on a log X axis that start at 0, horizontal bars.
- **Bubbles** (`xyBubble`, with the XY table layout `sized`). Area follows size, one scale for all series; a point with no size or a size of 0 or less is not drawn and is counted. A **size legend** (`Chart.sizeLegend`: reference circles under the plot, on by default for gallery bubbles) was added on 1 Nov 2026; Browser. Not done: bubbles coloured by a third column, room at the axis edges for the radius, changing the layout of an existing table.
- **Offset traces** (`xyOffset`, P8-013). Trace i is lifted by i × `traceOffset` (blank = automatic); built from a shifted copy of the table, so the table never changes; the offset is written on the figure and in the warnings. Not done: a scale bar of chosen length, a reversed order, an offset in X; tooltips and fit parameters are of the shifted values.
- **Separated scatter** (`groupedBy: 'series'`; grouped bars, floating bars, box plots and violins). The transpose of the usual layout: a group of columns for each series, the series name under it. Not done: a legend that omits what the names already say, a bracket over a group.
- **Three-way plots** (P8-028). `three.bars` / `three.dots` (series that share a factor are drawn together under the factor's name). Tested; `three.dots` was looked at in Chrome on sample tables. Not done: a bracket spanning the clusters of a category. The nested, trajectory and grouped before-and-after plots built with it were removed with subjects on 14 Nov 2026 (see Dropped).
- **Before and after.** The dots take the colour of their column; the lines take a colour for each subject (the palette's colours after those of the data sets; inspector → Plot → "Lines joining the rows" → Color by: Subject or One color; saved as `pairs.lineColour`). Browser. Not done: the legend keys still show a black line stub; grouped "Before and after" keeps one line colour.
- **Forest plot** (P8-029). A preset of lines over categories turned horizontal, from a grouped table "Mean (or median), Upper/Lower limits": square markers, whiskers from the typed limits, a dashed line at 0 (differences) or 1 on a log axis (ratios), no legend. **Summary rows** (Style → Summary rows) are drawn as diamonds from lower to upper limit. Nothing is pooled and there are no weights. Browser (`e2e/forest.spec.ts`). Not built: typed five-number box inputs.
- **Notched box** (`distribution.notched`). The box narrows at the median to median ± 1.58 × IQR / √n; with few values the notch is cut at a quartile, which is noted. The body is an outline, so a pattern fill does not apply.
- **Volcano plot** (`xyVolcano`). X is the log2 fold change, Y the p-value (or −log10); a p-value outside (0, 1] is not drawn and is counted; points past both thresholds are up (red) or down (blue); the three threshold lines are ordinary reference lines; the up and down points can carry their row titles. Not done: the legend does not list the three classes, labels cannot be edited or dragged one by one. A chart changed into a volcano plot gets the three threshold lines, as a new one does (if it has none yet).
- **Slices and the 10 × 10 dot plot** (`slices`, `dotGrid`), from the table of a pie. Slices: one bar for each row, a segment as wide as each share, its text under it (left out where it does not fit). Dot plot: 100 dots (circles or squares, of a chosen size) in a grid for each row, filled row by row from the top left; shares are exact, and a dot on the border of two parts is cut between them by area, filled from the left. Not done: no text beside the dot plot (the legend names the parts); slices and dots cannot be selected by part beyond the legend.
- **Pies and doughnuts.** The title of each pie is above it; the total, when it does not fit in the hole, is under it. A doughnut and several pies in a grid were not looked at.
- **Dot placement.** Dots of scatter, bar, box and violin charts can be Aligned, Jitter or Swarm (`jitter.swarm`; `swarmOffsets` in `chart/shared/parts/jitter.ts`): a swarm places each dot, from the lowest up, at the free place nearest the middle; `widthFraction` is the widest it may be. Not done: nested charts keep their clusters, a paired plot keeps its dots on the line, a dot with its own size is not taken into account, a swarm is made per column.
- **One kind of symbol in XY charts of replicates.** The symbols show the centre of each row or every replicate, never both (Symbols box → "Symbols show"). A graph that had both now shows the individual values only.
- **Heat maps** (P8-020, 021, 022). Sixteen ggsci gradients or a custom scale; seven statistics (mean, median, geometric mean, SD, SEM, %CV, N); intervals (`steps` 2–12 or up to 11 `breaks`); marks and colours for missing, excluded and out-of-range cells; cell size, group gaps, sparse labels and colour-bar controls. Defaults leave the earlier drawing unchanged. Tested with hand-computed values (`heatRanges.test.ts`). Not done: hatch fills for the marks; a replicate cell with some excluded values stays a normal cell.
- **Right Y axis on XY** (P8-014) for `xyScatter`, `xyLine`, `xyLineSymbols`, `xyBubble`, `xyBars`, `xySpikes` and `xyArea`. Own range, ticks, title, log scale, reversal and manual limits; cannot be broken. Reference lines, regions, extra ticks and data-unit annotations stay on the left axis; a bracket joining series on different axes is skipped with a notice; equal units concern X and the left Y only. Tested; not tried in a browser ("Plot data on", the Right Y axis section). Not done: extra ticks on the right axis; survival and histogram.
- **X error bars** (P8-004). XY table layout `xerror` (Y, Y ± error, X ± error), layer `xErrorBars`. Tested; not tried in a browser. Not done: X lower and upper limits, CSV import of the layout, a legend key, gallery entries.
- **Reference lines, extra ticks, regions, equal units** (P8-011, P8-012). Identity line and y = a + bx on XY charts; extra ticks (at most 12, with text, mark and a gridline of their own) on XY and on the value axis of bar, grouped, histogram and survival charts; shaded regions between two values (XY); equal units. Tested; not tried in a browser. Not done: oblique lines bound to results; extra ticks and regions on category charts.
- **Vector chart** was built on 28 Oct 2026 and removed on 4 Nov 2026 (type `xyVector`, table layout `vector`, gallery entry `xy.vector`). A file that has one is refused.
- **Totals.** 34 chart types and 57 gallery entries (`src/model/graph/chartTypes.ts`, `chartGallery.ts`).

### Annotations, brackets and text

- **Comparison brackets** (P8-018; built 29 October 2026, dragged and multi-line 1 November, removed 14 November 2026). Brackets with supplied labels, joined to data sets, are gone together with their layers, their placement and their room on the axis; a bracket is now drawn with Graphics (the bracket and bracket-with-text presets), which is anchored to the page or to data values and is exported as a shape. A file written with the old `brackets` is read, the brackets dropped, with a note (`FILE_FORMAT.md`).
- **Rich text** (P8-019). Subscripts, superscripts, Greek letters and symbols written as plain text, in every text drawn from the scene and in the title and panel labels of a layout page. The braces are required (`Mouse_3` is never changed). Syntax: README, "Rich text". Browser (title, rotated axis title). Not done: nested scripts, italic or bold runs, rich text in Results, CSV, tooltips and inspector lists (by decision).
- **Results in text** (P8-017). `{{mean Control}}`, `{{n Drug A}}`, `{{sd Control|2}}` in annotations, reference-line labels and bracket labels; the value of a reference line can come from a result (`valueFrom`). Browser for annotation text. Not built: tokens in axis titles, the chart title and the legend; a result inside a superscript needs extra braces.
- **Text tool and text settings** (14 Nov 2026). The graph toolbar has Select (V) and Text (T) tools; Text places a text where the graph is clicked, selects it, opens Notes and focuses its text box. A text has bold, italic, underline (drawn as a line under each line, so SVG, PNG and PDF show it), superscript and subscript buttons that write `^{…}` and `_{…}` round the selected letters, Undo and Redo, quick texts (ns, *, **, ***, ****), font family, colour, opacity, size with Larger and Smaller steps, alignment and line spacing (`Annotation.bold`, `italic`, `underline`, `fontFamily`, `align`, `lineSpacing`, all optional). The export report checks the fonts of the texts too. Tested (`annotations.test.ts`, `serialize.test.ts`, `AnnotationEditor.test.ts`); Browser (placing a text, typing into it, bold, underline, x² on a selected letter; Select on a bar, a dot, the title, the legend and an axis). Not done: bold or italic for part of a text (rich text has no bold or italic runs); the several-annotation box edits only size, colour and opacity; a click on the empty page of the chart selects the chart but leaves the inspector page as it was.
- **Annotations.** Anchor in data units (XY, survival, histogram: X and Y; columns and grouped: the value axis; pie and heat map: page only); arrow-key nudging; selection of several; drag. Browser on a bar chart; XY fields covered by tests. Not done: the right Y axis.
- **Label drag** (P8-019). A dragged point label of a column chart is stored as Custom with offsets (`dragLabelPatch`, one undo step). Only the arithmetic is tested; the drag was not seen in a browser. Not done: XY charts; a pause over 0.8 s in a drag makes a second undo step.
- **Legend.** Own order (never moves the marks), 1 to 6 columns, a numeric offset (`offsetXPt`, `offsetYPt`), a series with the same name and place in two factor clusters listed once, keys that follow the look of the series' layers (`legendKeyStyle`; the master legend of a page too), dot keys on dots-only grouped charts, keys capped at 20 pt. Not done: legend-only text; a hideable layer or own look for the size legend; keys for the layers of bars.

### Editing and inspector

- **Icon rail** (4 Nov 2026). The inspector's pages are an icon rail at its right edge: Graph, Plot, Axes, Legend, Analysis, Notes and Export; a page with nothing to set is left out; a click on the chart opens the page of what was clicked. The graph type is a menu at the left of the graph toolbar. Browser (`e2e/inspectorRail.spec.ts`). Not done: the type menu changes the type only (gallery variants such as bubbles or a forest plot are not offered); the arrow-key use of the rail is tested only in unit tests; narrow screens were not looked at. The old `TabBar` and `SectionBar` are used only by their test.
- **A graph is found as it was left** (8 Nov 2026). For each graph, for the session: the page of the rail, the tab on each page, the scroll and the sections opened or shut by hand (`state/inspectorNav.ts`). Browser (`e2e/inspectorMemory.spec.ts`). Not done: a layout's inspector, a table's own scroll and selection.
- **Layers.** Every chart is drawn from layers that can be hidden, reordered, kept out of the axis range and given a look of their own (XY, survival, column, grouped, histogram; not pies and heat maps, whose parts have no look to set; not stacked bars, which are ranged by their totals). Tested; the Layers sections of the column, grouped and histogram inspectors were looked at in Chrome. Not done: a look for the bodies of bars, boxes and violins (they keep the fill of the data set); dashed joins in column and grouped charts; the X range of a histogram (the bin grid).
- **Reset ladder.** The dot beside an overridden setting resets that setting for the data set; Reset beside the data-set selector clears its style, summary, part looks and point settings. Browser.
- **Several selected together.** Data sets (Ctrl, Cmd or Shift; Shift+Left or Right), points (column charts; "Selected points (n)" box) and annotations; fields where they differ show "Mixed"; one undo step. Browser for data sets and annotations. Tested only: the Mixed logic for points, the ring on several points. Not tried: Ctrl- or Shift-click on points, the "Selected points" box with differing values; the XY inspector only scopes its edits to the series of the points. Not done: pie, heat map and histogram inspectors (no per-data-set settings of this kind); dragging several annotations together.
- **Keyboard.** The chart takes focus: Left and Right select data sets, Down and Up go along the points (Page Up and Down jump ten; Home and End), then the title, legend, axes and annotations are stops; Escape selects the chart; Enter opens the settings; the selection is read out. Navigator: Up, Down, Home, End, Left and Right to fold. Grid: Home, End, Ctrl+Home, Ctrl+End. Browser. Not done: a `tree` role in the Navigator; no Playwright test of the annotation keys.
- **Sliders.** A number field's slider covers the range in use (`sliderMin`, `sliderMax`, `step`; presets in `ui/inspector/common/sliderRanges.ts`); a typed value may go to the field's limit. The ranges of a bar graph were read in Chrome; those of the XY, histogram, pie and heat map panels were set from the code. Titles and axis-title sizes in older files are not repaired.
- **Palette window.** One line per palette, "Colorblind friendly for the first N colours" (`safeColours` in `model/graph/colour/colorVision.ts`: the longest run of leading colours, of the first 6 compared, that stay clear under red-, green- and blue-weak vision). Browser.
- **Short choices as buttons.** A choice of two or three short entries is shown as buttons; lists driven by the project (graphs, data sets, results) stay drop-downs.
- **Settings on one page.** General (autosave, sample data, decimal separator), Graphs (default size, page background), Export (date and time in file names, default format, default layout PNG resolution). Browser (screenshot).
- **Accessibility.** An audit of every `.tsx` for names and landmarks (`accessibility.test.ts`; it sees host elements only), contrast tests of the CSS colours (muted text darkened to `#5a636d`; the primary button 5.6:1), a global 2 px focus ring. Browser: the start screen and the Settings dialog. Not done: a screen reader, a keyboard walk of every dialog and inspector, the contrast of data colours, forced colours, zoom.
- **Narrow screens** (OP-032). CSS for 900 px and 600 px; at 375 and 768 px: no sideways scroll, panels overlay, the navigator closes when an item is chosen. Browser (through an iframe). Not done: the inspector overlay is slightly clipped at the left edge at 375 px.

### Export and layouts

- **Formats.** SVG and PDF are vector; PNG is raster. A graph's PNG is at its own size (`GRAPH_PNG_DPI` = 96, one pixel for each pixel on screen, 96 dpi written into the file). The PNG of a layout page is at a resolution of 150, 300 (default) or 600 dpi, set in Settings and in the layout's Export page, and written into the file. Not offered: JPG, TIF, EPS (no encoder), a background choice (the page colour decides; none gives a transparent PNG).
- **Vector PDF** (G5, 1 Nov 2026). Written from the SVG of the export (`svgPdf.ts` reads it, `pdf.ts` writes the file): paths, rectangles, circles, clips, nested viewports, transforms, dashes, opacity states, and text as text in the standard fonts (Helvetica, Times, Courier; Symbol for Greek letters and signs); nothing is embedded; a character none has is written as "?" and the status line says which. Flate-compressed. A group's opacity is applied to each mark in it. Tested for every gallery graph; six PDFs looked at in Chrome's viewer; a PDF export is in `e2e/graphObjects.spec.ts`. Not done and not measured: time and size for 100 000 dots, other viewers, pattern fills (an SVG export has none).
- **Export page of a graph** (4 Nov 2026, `ui/export/ExportPanel.tsx`). Format tiles (PNG, SVG, PDF), a wide Export button that names the file (the name of the graph, with the date and time when that setting is on) and a report: size (px, pt, mm), fonts requested, used and missing, characters, warnings, known limits, Copy report (JSON). The layout page and the batch export keep their dialogs. Removed on 8 Nov 2026: the PNG resolution and print width of a graph (`pngDpi`, `printWidthMm`); a file that has `printWidthMm` opens and the value is dropped. Browser (`e2e/workflows.spec.ts`, `e2e/layouts.spec.ts`).
- **Export report of a layout page.** For a PNG the first line is the pixel size at the chosen resolution (A4 at 300 dpi: 2480 × 3508); for SVG and PDF it says only `A4 · 210 × 297 mm`. Glyph checks run for a graph and, for a page, once for each font on it (tested; the page check not tried in a browser). Not done: counts of clipped objects.
- **Batch export** (P8-031). "Export N…" in the Graphs folder writes the selected graphs as one stored ZIP (`util/zip.ts`, CRC-32, UTF-8 names, no ZIP64, no dependency; opened with Windows Expand-Archive), from one state of the project; date-stamped names with `_2` numbering; the canvas guard runs in the plan and in the job. Tested with a fake raster renderer; the PNG and PDF paths and the dialog not tried in a browser. Not done: a per-graph font and glyph report, a cancel button; the ZIP keeps its own name (`<project>_graphs`).
- **Master legend of a page** (P8-016). `Layout.legend` (bottom or right; text size 6–24 pt; hide the graphs' own legends); entries merged by name and look; the band is taken from the panel area. Tested; not tried in a browser. Limits: only graphs whose own legend is visible give entries; heat maps have none; entries with the same name, colours and key structure but another symbol shape merge; in free placement the boxes are not moved out of the band.
- **Texts on a page layout** (14 Nov 2026). `Layout.annotations`: the Select and Text tools on the layout's toolbar, a Notes page in its inspector with the same text editor as a graph (`AnnotationEditor` now takes its changes as callbacks), drag to move, Delete to remove; drawn by `annotationElements` in `drawLayout`, so the preview and every export show them; their fonts and characters are in the export report. Tested (`layoutPage.test.ts`, `serialize.test.ts`); Browser (place, type, bold, drag, deselect, Delete and Undo). Not done: while a page text is dragged its outline moves and the text follows when it is let go; no arrow-key nudge; several page texts cannot be selected together.
- **Layout work.** Panels, scaling modes, free placement, page title and panel letters in rich text. Not started: alignment of plot axes across panels (P8-023, P8-024).
- **Large graphs.** Above 100 000 dots the preview of a column-family graph is simplified (`denseDots.ts`); the export is exact. Not done for XY, grouped, survival and histogram.
- **Fits in a worker.** Nonlinear fits run in a Web Worker with a pending state; results are keyed by their inputs (design: roadmap, "Fits in a worker"). Browser (`e2e/fitWorker.spec.ts`). Not done: the Results sheet, a worker pool, a cancel button, 100 000 points, the production build.

### Tests and documentation

- **Playwright** (`e2e/`, `npm run e2e`): runs in the installed Chrome, each test in a fresh profile; covers editing, exclusion, duplicate, save and open, PNG size, the keyboard of the grid, chart and Navigator, fill series, dialog focus, several data sets, annotations, legend, the narrow window, brackets, the forest plot, table type, the inspector rail and its memory, layouts and workflows.
- **README capability table** is generated from `src/model/graph/capabilities.ts` and checked by a test; update it with `UPDATE_README=1 npx vitest run src/model/graph/capabilities.test.ts`.
- **Reference values from outside the code.** The two-phase exponential fit is checked against NIST MGH17 (all parameters and standard errors to 6–9 digits) and its bands against a delta method worked out in the test. The other fit models have no outside reference.
- **`docs/example.oplot`** gains new default fields by hand; do not regenerate it (that gave a 1000-row file).

## Known issues

Found by a read of the whole source on 5 November 2026 and not fixed. Proposals, by area.

| Area | Issue |
|---|---|
| Column and grouped charts | Hatch patterns turn with a horizontal chart (horizontal lines draw vertical; the legend key does not). The grouped legend key ignores bar opacity and "no fill". Grouped bar labels do not clear the replicate dots. Stacked piles start at 0, not at the baseline (check whether intended). Grouped dots in a gap are not counted in the warnings. Much code is copied between `columnModel.ts` and `groupedModel.ts`; grouped does not memoise its box and violin statistics; the summary cache re-hashes all values on each build. |
| XY and axes | Bars at numeric X on a log axis are dropped without a note. XY bars have no tooltip. Natural-log ticks read "2.71828182846". XY marks are not chunked like column marks (a 200 000-point scatter rebuilds every element on a selection change). The custom heat-map interpolator is built per cell. Run-to-path code is written five times; break handling is copied between time and numeric axes. A survival confidence band still takes a vertex inside an axis gap to the nearer edge (the clip trims the fill). |
| Model and state | Deleting a column leaves references in other charts (extra data sets, hidden IDs, order, layer styles, brackets, reference lines). The cell limit is per table. The start-up backup doubles the storage used; each autosave reads and hashes the stored text twice. `setExcluded` and `setSubject` cost columns × cells. Colour regexes and line-style lists are repeated in `serialize.ts`. |
| Statistics | Exponential fits fail when X starts far from 0 (the amplitude is moved back to X = 0 and overflows). `normalQuantile` is accurate to about 1e-9, not the 1e-10 of the contracts. A deferred fit's slot is not released on its early returns. Worker errors are not caught in the worker. Polynomial coefficients over raw X lose digits. A straight-line fit of 24 replicates once gave other parameters than an agent's own least-squares line; the app's fit equals least squares over every replicate to 15 digits (`xyDualAxis.test.ts`), so the difference was probably a different set of points, but this is not proven. |
| Interface | The grid re-renders every visible cell per key and per scroll event, without windowing columns. Inspector number fields ignore the comma separator. CSV line numbers in messages count from the filtered records, and blank lines of a one-column file are dropped. Four dialogs rebuild the dialog frame by hand. Style-scope code is copied between the Column and XY inspectors. Escape during a rename may save it (not checked in Chrome). Bracket layer names in the Layers list show the raw markup (by decision). The table-order default draws a V-shaped line for the sample XY table in the line presets. |

## Dropped and not adopted

Dropped by decision on 1 November 2026 (ROADMAP, "Decisions"): dot apportionment as a graph, residual plots, ROC, Q-Q and Bland–Altman plots, the exact binomial interval, Holm and BH, fit validation for models other than the two-phase one, the axis alignment of layout panels, a worker pool and cancel button, the fits of the Results sheet in a worker, a look for the bodies of bars, boxes and violins, boxes and violins at numeric X, new families, and the open items of small screens and accessibility. Statistics taken from R (To do, item 2) may reopen some of them.

Removed by decision on 14 November 2026: **subjects**. The free-text `subject` on each observation (Subject… in the grid, the "<Group> subject" CSV column) and the three graphs that read it: nested dots (`jitter.bySubject`), one line for each subject on XY charts (`lineConnect: 'subject'`) and grouped bars joined by subject (`pairs.bySubject`, gallery items `cat.nested`, `xy.trajectory`, `grp.paired`). Pairing is by table row (the before-and-after plot). Older files open with these ignored (`lineConnect: 'subject'` is read as `x`), with no notice; a subject column in a CSV file is skipped with a note. Tested in code; not tried in a browser.

Not adopted from the outside reviews:

- Workarounds from other tools: repeated medians to fake a box, estimate and limits as three "replicates", a dummy graph for a legend, 1.99/2.00 range limits.
- Silent downsampling of exports, and any claim of parity with other tools in packing, violins or splines.
- ANOVA, post-hoc and model-selection workflows (roadmap: out of scope).
- Replacing zero by a tiny value before a log axis.
- "Property tests" for OP-015 and OP-001 as separate work: they are tests of the fixed code.
