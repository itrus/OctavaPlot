# P3 Editing audit (roadmap step 3)

Date: 27 October 2026. Read-only audit; no source or test file was changed.

## Method

Read the source under `src/ui`, `src/state`, `src/model`, `src/chart/shared/scene` and `src/styles.css`, with `grep` for the named features. Nothing was run in a browser, so layout findings come from CSS and components only. "Not checked" means not read. Sizes: S half a day, M one to two days, L several days. Exit criterion: a figure can be reproduced from numeric inputs without dragging.

## Drag-only list

Things that can only be done by dragging, or that have a numeric field but no keyboard route to the object:

1. Moving an annotation on the canvas: numeric Left/Top and arrow keys exist in the inspector, so this one is not drag-only. Kept here to be explicit.
2. Reorder of Navigator and folder items by drag and drop: `nudgeItems` buttons "Move earlier/later" exist in the folder view (`FolderView.tsx` l.70). The Navigator itself has no reorder control (not checked beyond the grep).
3. Layout frames (free arrangement): drag and resize handles, but Left/Top/Width/Height fields exist (`LayoutView.tsx`).
4. Legend placement: neither drag nor numbers; only three fixed positions.
5. Selecting a data point, label, bar, error bar or legend on the canvas: pointer only (`GraphView.tsx` `onPointerDown`). Group selection has the inspector select.
6. Point selection for the per-point label controls: from the canvas only; there is no row picker. Column inspector only.
7. Data grid range selection by mouse drag has a keyboard equivalent (Shift-arrows).
8. Inspector and Navigator width: Splitter has keys, so not drag-only.
9. Chart zoom and scroll: zoom has buttons and a slider in the status bar; panning is scroll bars or wheel (no keys: not checked).

Genuinely drag-only today: items 4 and 5 and 6. Everything else has a numeric or keyboard route.

## Build items, in priority order

Ordered by what the exit criterion needs first, then by size.

1. **Annotation anchored in data coordinates, with a numeric offset (M).** Today `xFrac` and `yFrac` are fractions of the chart, so a figure with changed axis limits cannot be reproduced numerically. Add an anchor kind (chart fraction or data X/Y) and a relative offset in pt, as the point labels already do. Needs a file-format migration and a scene change in `annotations.ts`.
2. **Legend position as numbers (S).** Add an offset X and Y (pt) next to the three positions; keep the enum as the origin.
3. **Reset ladder (M).** Field: a reset control on every `overridden` field (clears one key through `clearObjectKeys` and its group equivalent). Section and data set: wire the existing `resetStyle` and `clearSummaryOverrides` to a button in the data set row. Graph: keep `resetAllDataSets`, and state in its tooltip what it keeps. Tests exist for the commands; add UI-level tests with the same DOM-free approach as `controls.test.tsx`.
4. **Mixed-state multi-selection (L).** Extend `Selection` to a set of data sets (then points and annotations); resolve each control's value as same or "Mixed"; an edit writes all members. Prerequisite for Global no longer hiding differences. Start with data sets only.
5. **Property search (M to L).** Decide first: DOM filter over all rendered tabs (M) or a label registry derived from the inspector components (L). A registry is also useful for a keyboard route to a field and for tests that every field has a name.
6. **Keyboard selection on the canvas and in the Navigator (M).** A list of objects (data sets, points, labels, annotations, legend) reachable by key, a point picker by row, and arrow keys in the Navigator.
7. **Small-screen fixes (S).** Close the Navigator overlay after choosing an item when it is an overlay; clear or age the status message on a view change; check the inspector rows at 375 px in a browser and fix `.field-label` or row wrapping; correct `BACKLOG.md` l.75.
8. **Grid fill (S).** Ctrl+D (fill down), Ctrl+R (fill right), Home/End.
9. **Reference line label position and style (S).**
10. **Playwright workflows for keyboard grid, inspector and dialog focus (roadmap P5, M).** Without them none of the keyboard items above is tested beyond the pure helpers.

## Exit criterion status

Not met. A figure's data, axes, sizes, reference lines, point-label offsets and layout boxes can be set numerically. Annotation placement in data units, legend placement, mixed selections and field-level reset are missing, and the canvas cannot be operated by keyboard.
